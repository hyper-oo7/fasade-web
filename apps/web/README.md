# Fasade Web Application

This is the Next.js frontend for Fasade.

## Features
- Server-Side Rendered (SSR) for optimal SEO
- 150+ dynamically generated, medically-accurate SEO skincare guides
- Tailored for Vercel deployment
- Structured JSON-LD Data for Google Rich Snippets

## Development

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
